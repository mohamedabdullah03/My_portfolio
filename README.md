# Mohamed Abdullah S — Portfolio

Responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser. For best results, run a local static server:

```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000.

## Personalize before publishing
- Replace the LinkedIn link in `index.html` with your actual profile URL.
- Replace the GitHub link in `index.html` with your actual profile URL.
- Optionally add project repository links and project screenshots.
- Resume PDF is included at `assets/resume.pdf`.

## Publish
Upload this folder to GitHub Pages, Netlify, Vercel (static), or any static hosting provider.
